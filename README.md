# Suuush

Installable mobile web app (PWA) for ambience: white, pink, brown, and grey noise, jungle, sea waves, and a fan. Background playback and notification controls on Android Chrome when added to the home screen.

## Commands

```bash
pnpm install
pnpm dev          # local dev (no service worker)
pnpm build        # production + PWA
pnpm preview      # test install / offline shell
pnpm lint
pnpm check-types
```

## Android

1. Open the deployed or preview URL in Chrome.
2. **Add to Home screen**.
3. Play, switch apps or lock the screen — audio continues.
4. Use play/pause and previous/next in the notification shade.

Dismiss the notification to stop playback.
